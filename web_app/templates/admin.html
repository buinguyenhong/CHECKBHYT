💡 Hướng dẫn:
1. Chọn khoa cần trả hồ sơ → Xem trước để kiểm tra danh sách ca.
2. Bấm Mở khóa (Trả khoa) để sinh script SQL đưa BenhAn.TrangThai về DaXuatVien.
3. Copy script vào SSMS và chạy. Thông báo cho khoa sửa hồ sơ trên HIS.
4. Sau khi khoa báo sửa xong, bấm Khóa lại để sinh script đưa TrangThai về DaThanhToan.
